# Brand Identity: KoraCRM

- **Name:** KoraCRM
- **Palette:** Deep Teal `#0f766e` primary accent, Slate `#0f172a` text, `#ffffff` / `#f8fafc` surfaces (11/11 WCAG AA/AAA passing pairs).
- **Typography:** `Inter` (open-source) + `JetBrains Mono`.
- **Icons:** `Lucide` (MIT) + custom SVG chat-bubble mark (`frontend/public/icon.svg`).
- **Voice:** Direct, fast, reliable — zero BaaS jargon, clear empty states, actionable CTAs.
